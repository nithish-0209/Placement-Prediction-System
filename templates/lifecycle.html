Automated drift-triggered pipeline re-execution and model versioning.

Supervised vs Unsupervised vs RL

Categorization of Machine Learning Paradigms and PlacementPredict's Role:

Paradigm Nature of Target PlacementPredict Mapping
Supervised Learning Ground truth labels $y \in \{0, 1\}$ or $y \in \mathbb{R}$ present during training. Core Task: Classification of placement status ($y \in \{0, 1\}$) & Salary Package Regression ($y \in \mathbb{R}$).
Unsupervised Learning Unlabeled inputs $X$; discovers latent manifolds and densities. Synthesizer: K-Means student archetypes, DBSCAN density, and Isolation Forest profile anomalies.
Reinforcement Learning Sequential policy learning via environmental reward signals $R_t$. Not applicable: No dynamic state-action feedback environment or interactive policies here.

Training-Serving Skew & Feature Stores

The canonical bug class responsible for the vast majority of production ML failures:

  • !
    What is Training-Serving Skew? A condition where features seen by the model during inference differ in distribution, schema, or computation logic from those seen during training (e.g. standardizing with test batch mean instead of frozen training mean).
  • ✓
    How PlacementPredict Prevents It: A single Scikit-Learn ColumnTransformer is fitted exclusively on training data and exported as a serialized joblib pipeline. Online requests pass through this exact frozen pipeline.
  • ⚑
    Why Feature Stores Exist (Feast): In industrial distributed systems, offline feature tables (BigQuery/Snowflake) and online low-latency caches (Redis) must adhere to point-in-time correctness, preventing data leakage.

Tracing One Prediction: Online vs Batch

Online Prediction (REST API)

  • Single student HTTP POST payload ingested via JSON.
  • Schema validation & null check executed in-memory.
  • Transformer pipeline imputes, scales, and extracts cluster distance.
  • Platt-calibrated HistGradientBoosting model computes $P(\text{Placed})$.
  • Salary regressor predicts LPA if placed.
  • Inference latency logged to telemetry buffer (< 2ms target).

Batch Prediction (Vectorized)

  • 1,000 to 50,000 student CSV file ingested.
  • Vectorized matrix multiplication & tree traversal in C/C++.
  • Throughput prioritized over millisecond latency.
  • Aggregate statistics computed for cohort level reporting.
